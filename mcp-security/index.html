Securing MCP & Agentic AI: Tool-Call Authorization That Can't Be Bypassed

Model Context Protocol turns AI agents into actors that read the web, call tools, write memory, and move money. That's a new attack surface: every tool description is attacker-reachable context, and every grant is a standing door. The rule that governs L3 of the SAHA31 standard is simple: an agent's effective permission set is the capability-union across every tool it can reach — one over-granted plugin breaks the whole stack.

01The Four L3 Controls

  • Signed tool manifests. Every plugin ships a manifest (capabilities, scopes, egress hosts, confirmation policy), signed and verified at load. Unsigned or drifted manifests are rejected — that's what stops supply-chain tool swaps and description smuggling.
  • Deterministic JSON-RPC gating. Every tool call passes a policy gate that evaluates the union of live grants, not the individual request. No LLM in the loop for the decision — the gate is code, auditable, and non-overridable by prompts.
  • Confirmation budgets & kill-switch. High-impact actions carry per-session budgets (confirm: none / budget / human). A runtime kill-switch stops the agent mid-chain — and the switch itself is test-executed every release, because an untested kill-switch is decoration.
  • Tenant isolation. Agents, memory, and grants are hard-partitioned per tenant; cross-tenant bleed is a measured attack class, not a hope.

02The Attacks This Kills (SAHA31 catalog rows 41–60)

Tool description injection, capability-union escalation, sandbox escape via code execution, confirmation-budget exhaustion, kill-switch bypass races, tenant bleed, runtime manifest tampering, JSON-RPC forgery, tool-call replay, argument injection via retrieved data, agent-to-agent confusion, and cross-tenant grant union — twenty cataloged attack families, each owned by L3 (with L4 co-ownership where data integrity is the failure point).

03What Enterprises Audit Next

Which plugins are live, which grants are unbounded, whether any tool can reach egress without a policy gate, and whether the kill-switch has ever been test-fired. Those four answers decide whether your agentic stack is a controlled surface or a standing execution path for a future exfiltration.
