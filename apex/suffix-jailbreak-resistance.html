03FAQ

Why do adversarial suffixes keep working after a model update?

The loss functions that train suffixes target behavioral patterns that persist across fine-tunes. If your regression suite does not re-run the suffix catalog on every new model version, a transferred suffix will bypass a model you believe you already tested.

How do you defend against adversarial suffix jailbreaks that survive to production?

Run suffix-transfer tests on every model generation before cutover, with a versioned transfer corpus stamped into the release record. The meta-loop mutates suffix families monthly so the winning bypass never rests.
