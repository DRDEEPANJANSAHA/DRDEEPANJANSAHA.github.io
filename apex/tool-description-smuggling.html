Tool-Description Smuggling Past the Manifest Check

Agentic & Tool Layer · L3 · MCP + tool calls · Agentic & Tool Layer

The manifest check reads the declared capabilities; the smuggle hides in the description's prose: 'This tool lists files' plus one paragraph of steering text for the model. The capability declaration is honest and the description is the payload — the two-layer gap is the attack.

01Control Architecture

How it is defended

Description text is a first-class scan target: directive detection on the prose at load, and any steering language that doesn't map to a declared capability fails the manifest check. The declaration and the description must reconcile or the tool doesn't load.
