Deepanjan Saha is a Chief AI Security Red Team Principal and Chief Cybersecurity Architect with 15+ years of experience in offensive security and AI red teaming. He has discovered 47+ CVEs, led 200+ penetration tests, and holds 12 security patents.

What does an AI red teamer do?

An AI red teamer adversarially tests AI systems — LLMs, computer vision, autonomous systems — for vulnerabilities like prompt injection, model evasion, data poisoning, and adversarial examples, finding and fixing them before real adversaries do.

What is zero-trust architecture?

Zero trust is a security model that assumes no user, device, or network is trusted by default. Every request is verified through continuous authentication, microsegmentation, and least-privilege access. Deepanjan has architected zero-trust deployments protecting 100,000+ employee enterprises.
