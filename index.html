N10 // THE ARCHITECTURE, ANSWERED

Boardroom questions, in plain terms.

What does a Chief AI Security Architect do that a traditional red team does not?

A traditional red team delivers a list of findings this week. A Chief AI Security Architect delivers a measured, multiplicative defense stack: six instrumented layers, per-layer catch rates on a versioned attack corpus, and an end-to-end residual-risk number with a trend line. The unit of work is a number you can hold leadership to, not a PDF you archive.

What is CAISO?

CAISO stands for Certified AI Security Officer — the designation for a practitioner credentialed across the full generative-AI security stack: prompt and context injection, agentic tool isolation, model supply chain, eval integrity, and release governance.

What is the residual risk formula?

Residual Risk = the product of the miss probabilities of each defense layer. If six independent layers each miss 10% of an attack class, end-to-end residual risk is 10 to the power of 6 — one in a million.

How is securing an AI agent different from securing a chatbot?

A chatbot's surface is one conversation. An agent's surface is a tool chain: MCP servers, sandboxes, retrieved documents, memory writes, and egress. Each tool grant composes with the others, so the defense must isolate execution, sign tool manifests, budget confirmations, and hold a runtime kill-switch.

How do you defend against prompt injection without breaking functionality?

By separating the data plane from the control plane. Fetched, retrieved, pasted, or tool-returned content is treated strictly as data: it can inform the model, never direct it. Combined with deny-by-default tool grants and human confirmation for high-stakes actions, the model keeps full usefulness.

What does an AI release gate look like?

Eight checks run per release, including a structural check that fails the gate if any layer maturity falls below threshold or residual risk exceeds one percent. No checkbox can override the math.

Which standards and toolchains are you aligned to?

MITRE ATLAS for attack taxonomy, the OWASP LLM Top 10 for risk reporting, and the NIST Generative AI profile for governance language. Open toolchain: Inspect AI, garak, PyRIT, promptfoo, JailbreakBench, HarmBench, AgentDojo, Llama-Guard 3, Rebuff, NeMo Guardrails, e2b, gVisor, nsjail.

How is an AI red-team engagement scoped?

From the 100-attack catalog down to your actual attack surface: which layers exist, which tool grants are live, which release boundaries matter. A typical flagship is Map → Instrument → Gate in the first 6 weeks; the M(t) loop and Mastery program run continuously after. No report-only scopes accepted.
